# Nexora

A full-stack cryptocurrency tracking application built with React.js and Django REST Framework.

Nexora provides real-time cryptocurrency market data, detailed coin information, interactive charts, and a responsive interface. The project started as a React frontend and has been extended with a Django REST backend to handle application logic, APIs, and data management.

## Live Demo



> Frontend is currently deployed on Vercel.

## Overview

Nexora is built to replicate the experience of a real-world cryptocurrency tracking platform.

The frontend is built with React.js and Tailwind CSS, while the backend is powered by Python and Django REST Framework. The application communicates with cryptocurrency APIs to retrieve market data and exposes backend endpoints for the frontend to consume.

The project focuses on building a complete frontend-to-backend workflow rather than just a standalone UI.

## Features

- Real-time cryptocurrency market data
- Search and browse cryptocurrencies
- Detailed information for individual coins
- Interactive price charts
- Dark / Light mode
- REST API integration
- Responsive design for mobile and desktop
- React frontend with Django REST backend
- API-based communication between frontend and backend
